# Contributing

Start with the README and [validation guide](docs/VALIDATION.md). Open an issue describing the
problem before a large change; small reproducible fixes and clearer setup instructions are welcome.

Run the documented checks before submitting a pull request. Include the command, expected behavior,
actual behavior, and the smallest public or synthetic example needed to reproduce a bug.

Do not upload tokens, personal IP addresses, filesystem paths, prompts, model weights, databases,
or private logs. Replace identifying details with placeholders. Keep upstream attribution and licenses.
Contributions to original project code are under MIT.
